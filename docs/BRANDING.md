# 🎨 LiteLLM Gateway Brand Guidelines

## Brand Identity

**LiteLLM Gateway** is the intelligent choice for developers who value both performance and cost-efficiency. Our brand reflects:
- ⚡ **Speed** - Fast, efficient AI routing
- 💰 **Value** - Maximum savings with quality maintained
- 🎯 **Intelligence** - Smart model selection
- 🌟 **Reliability** - Always works, always optimized

---

## 🎯 Logo

### Primary Logo
```
🚀 LiteLLM Gateway
```

The rocket emoji (🚀) is our primary logo. It conveys:
- Speed and acceleration
- Innovation and forward-thinking
- Energy and momentum
- Trust and reliability

### Logo Variations
- **Light theme**: #667eea with white background
- **Dark theme**: #00ff00 with dark background
- **Monochrome**: Black on white

### Logo Sizing
- **Minimum size**: 32px (height)
- **Padding**: 16px minimum on all sides
- **Clear space**: Keep 16px clear space around logo

## 🔤 Typography

### Font Family
- **Primary**: Helvetica Neue, Helvetica, Arial, sans-serif
- **Monospace**: Courier New, Courier, monospace
- **Web Safe**: System font stack

### Font Sizes
- **H1** (Hero): 3.5rem (56px), Weight 800
- **H2** (Section): 2.5rem (40px), Weight 700
- **H3** (Subsection): 1.8rem (28px), Weight 600
- **Body**: 1rem (16px), Weight 400
- **Small**: 0.9rem (14px), Weight 400

### Font Weights
- **Light**: 300 (not commonly used)
- **Regular**: 400 (body text)
- **Medium**: 500 (descriptions)
- **Semibold**: 600 (labels, small headings)
- **Bold**: 700 (headings)
- **Extrabold**: 800 (hero text)

## 🎨 Visual Style

### Buttons

**Primary Button**
- Background: #00ff00 (Neon Green)
- Text: #000000 (Black)
- Padding: 14px 32px
- Border Radius: 6px
- Font Weight: 600
- Hover: Background #00dd00, Transform translateY(-2px)

**Secondary Button**
- Background: Transparent
- Text: #667eea (Brand Purple)
- Border: 2px solid #667eea
- Padding: 12px 28px
- Hover: Background rgba(102, 126, 234, 0.1)

### Cards

- **Background**: #2a2a3e or white
- **Border Radius**: 8px
- **Box Shadow**: `0 2px 10px rgba(0, 0, 0, 0.05)`
- **Hover Shadow**: `0 10px 25px rgba(0, 0, 0, 0.1)`
- **Padding**: 30-40px
- **Transition**: all 0.3s ease

### Spacing
- **Base unit**: 8px
- **Padding**: 10px, 20px, 30px, 40px
- **Margins**: 10px, 15px, 20px, 30px, 40px, 60px, 80px
- **Gap**: 20px, 30px, 40px, 60px

## 📐 Design Principles

### 1. **Clarity**
- Clean, uncluttered interfaces
- Clear hierarchy and visual flow
- Obvious call-to-actions

### 2. **Efficiency**
- Minimal but meaningful animations
- Direct paths to important actions
- No unnecessary elements

### 3. **Consistency**
- Unified visual language across all touchpoints
- Consistent spacing and sizing
- Predictable interactions

### 4. **Accessibility**
- 4.5:1 contrast ratio for text
- Clear focus states for keyboard navigation
- Readable font sizes (minimum 16px)

## 🌐 Usage Guidelines

### Website
- Use the gradient background for headers
- Use #667eea for primary CTAs
- Use #00ff00 for success and completion states

### GUI Application
- Dark theme (#1e1e2e background)
- #667eea for headers and accents
- #00ff00 for success indicators
- #f44336 for danger/stop actions

### Documentation
- Use #667eea for headers
- Use code syntax highlighting for terminal output
- Use brand colors for emphasis and highlights

### Social Media
- Use gradient logo in posts
- Use neon green for accent text
- Maintain consistent styling across platforms

## 💚 Brand Voice

### Tone
- **Professional** but approachable
- **Direct** - no unnecessary words
- **Empowering** - help developers succeed
- **Transparent** - show real numbers and benefits

### Key Messages
- "Intelligent AI Routing"
- "Save 91% on costs"
- "Quality you trust, costs you'll love"
- "Smart model selection for every task"

### Example Phrases
- ✅ "Cut your AI costs by 91%"
- ❌ Avoid: "Reduce expenses by generating lower-quality responses"
- ✅ "Route requests to the perfect model"
- ❌ Avoid: "Use cheap AI models for simple tasks"

---

## 📋 Checklist

When creating materials, ensure:
- [ ] Brand colors match hex values exactly
- [ ] Logo has proper clear space
- [ ] Typography follows size and weight guidelines
- [ ] Buttons have hover states
- [ ] Contrast ratios meet accessibility standards
- [ ] Spacing follows 8px base unit
- [ ] Voice matches brand guidelines
- [ ] Gradient used correctly in headers
